# Lamp reconstruction comparison

[Original input sheet](../input/source.png) · [Matching view](matching-view.png) · [Rear](rear-view.png) · [Side](side-view.png)

Source: repository `references/renders/render_desk_lamp_v1.png`, copied unchanged to input/source.png. The reconstruction uses the **top-left Photorealistic panel**; the other style panels are not reconstruction targets. The full sheet is retained to preserve attribution/context.

Observed: yellow tapered shade, black round base, two arm segments and circular hinges. Inferred: physical dimensions, arm thickness, joints, hidden shade interior, bulb and cable routing. The model has editable volumetric geometry and an open shade; no reference plane is presented as a reconstructed object.

The matching view gives a similar three-quarter silhouette, but angles, opening visibility and proportions differ. Alternate views confirm plausible depth, not measured accuracy. See review.md for the one-pass limitations.
