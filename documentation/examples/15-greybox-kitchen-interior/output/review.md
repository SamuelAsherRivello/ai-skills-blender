# Kitchen-interior greybox review

This greybox answers whether an open room shell, an L-shaped kitchen work zone, a refrigerator mass, and a central circulation path read immediately. It uses floor and wall planes plus four rectangular kitchen masses only.

It intentionally omits cabinet fronts, doors, windows, sink details, furniture, decoration, texture maps, UVs, and modifiers.

## Verification

The saved 960×540 render was inspected visually: the open viewing side shows the L-shaped counter area, refrigerator block, island, and the circulation void around them. The adjacent GLB was opened in a local browser viewer, where the floor, room boundaries, and all kitchen masses were present and orbit controls were available. Public HTTP access remains unverified because this example has not been published.
