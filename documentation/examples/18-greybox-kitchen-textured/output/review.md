# Slate-textured kitchen greybox review

This greybox answers whether an open room shell, an L-shaped kitchen work zone, refrigerator mass, and central circulation path read immediately. The selected hue is Slate; every material uses the same editable Object-coordinate checker graph with a mapping scale of 3.0 and restrained value contrast.

The category map is `Floor → Greybox_Slate_Floor`, `Wall → Greybox_Slate_Wall`, `Counter → Greybox_Slate_Counter`, and `Appliance → Greybox_Slate_Appliance`; both counter runs and the island share the exact `Counter` datablock. It intentionally omits cabinet fronts, doors, windows, sink details, furniture, decor, image textures, UVs, and modifiers.
