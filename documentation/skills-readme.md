# Blender Skills

Browse the Blender skills by task. Select a starting skill for the result you want; use the focused skills when that part of the workflow needs attention. Every skill can also be called directly. Codex uses `$name`; Claude Code uses `/name`.

| Skill | Use it for | Typical role |
|---|---|---|
| [blender-setup](../skills/blender-setup/SKILL.md) | Check the Blender connection and diagnose setup issues | Start here |
| [blender-create-visual-target-2d](../skills/blender-create-visual-target-2d/SKILL.md) | Create a prompt-specific target for parallel 3D feedback | Start here for a visual target |
| [blender-create-model](../skills/blender-create-model/SKILL.md) | Create a prop or character | Start here for a model |
| [blender-create-environment](../skills/blender-create-environment/SKILL.md) | Build a room, landscape, or modular scene | Start here for a scene |
| [blender-procedural-geometry](../skills/blender-procedural-geometry/SKILL.md) | Build editable generators and repeated geometry | Focused step |
| [blender-materials](../skills/blender-materials/SKILL.md) | Create or refine surface materials | Focused step |
| [blender-uv-bake](../skills/blender-uv-bake/SKILL.md) | Unwrap meshes and bake texture maps | Focused step |
| [blender-light-camera](../skills/blender-light-camera/SKILL.md) | Refine lighting and camera composition | Focused step |
| [blender-render](../skills/blender-render/SKILL.md) | Render the current scene and verify outputs | Start here for a render |
| [blender-rig-animate](../skills/blender-rig-animate/SKILL.md) | Rig an asset or create animation clips | Start here for animation |
| [blender-game-export](../skills/blender-game-export/SKILL.md) | Export an asset for a game engine | Start here for export |
| [blender-review-optimize](../skills/blender-review-optimize/SKILL.md) | Review asset quality and reduce rendering or geometry cost | Focused step |
| [blender-convert-3d-2d](../skills/blender-convert-3d-2d/SKILL.md) | Render a model into sprites or other 2D views | Start here for 2D output |
| [blender-convert-2d-3d](../skills/blender-convert-2d-3d/SKILL.md) | Reconstruct a model from an image | Start here for reconstruction |

The curated Codex package also includes [blender-create-greybox](../.codex/skills/blender-create-greybox/SKILL.md) for quick spatial, layout, and silhouette studies. It is not in the shared or Claude catalog.
