# Proposal

## Why

Example 02 meets technical delivery checks but looks like a simplified miniature beside the user's photographic and architectural targets. The suite needs evidence-led visual judgment that transfers to other subjects and requested styles.

## What Changes

- Inspect all eight feedback targets and translate their useful visual cues into a style-aware evaluation brief without copying a specific building.
- Build example 02 five times from empty owned scenes, preserving the original prompt, baseline, every attempt, and measured settings. Inspect each render and revise one or more canonical Blender skills after each attempt.
- Apply each lesson to subsequent fresh construction, recording the skill versions, observed weakness, change, outcome, and regressions. Reusable construction helpers are allowed; reopening or incrementally editing an earlier attempt is not a fresh build.
- Improve reference interpretation, construction depth, material scale, camera/light choices, and visual acceptance where results support a change. Keep cartoon, sprite, and other styles intentional rather than imposing realism universally.
- Verify final guidance with small non-architectural realistic-prop and stylized-subject checks; synchronize Codex and Claude packages and validate metadata and outputs.
- Deliver a comparison report and the best inspected attempt as the example's main output, with original outputs preserved. Keep renders at 1280x720, previews 640x360, and a soft target under 30 seconds per still.

## Capabilities

### New Capabilities

- `blender-visual-feedback`: Repeatable fresh-scene feedback iterations and reusable, style-aware visual quality guidance supported by inspected outputs.

### Modified Capabilities

None. No main specs exist. This supplements the active add-examples change without approving its milestone 1 or starting its remaining examples.

## Impact

Canonical skills and generated client packages; example 02 input/output evidence; focused validation helpers only where useful. Use the installed official Blender Lab MCP and existing Blender, with no new server or paid service. Preserve unrelated working changes and the user's feedback-target directory. No commit or push.
