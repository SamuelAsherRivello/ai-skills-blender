# Visual reference gallery

User-supplied PNG reference collection for humans and AI. Original folder names, filenames and bytes are preserved. Source/creator/license: not supplied (unknown).

Browse [camera](camera/README.md), [colors](colors/README.md), [lighting](lighting/README.md), or [renders](renders/README.md).

Focused indexes: [architectural styles](architectural-render-styles/README.md) and [character styles](character-render-styles/README.md). These link to the same source files rather than duplicating them.

AI: inspect the actual selected image before describing or applying visual characteristics. Names below are file labels, not verified descriptions of style. Translate observed camera, lighting, palette and material choices into Blender settings. Record the filename used.

The gallery remains optional. For an installed skill, supply its absolute gallery path in your request. Textual styles work without it. For new references, prefer descriptive kebab-case names and record source/credit and license when known.
