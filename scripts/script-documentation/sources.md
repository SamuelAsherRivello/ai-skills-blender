# Sources and boundaries

Original workflows are informed by:
- [Official Blender Lab MCP](https://www.blender.org/lab/mcp-server/)
- [Official source](https://projects.blender.org/lab/blender_mcp)
- [Codex skill documentation](https://learn.chatgpt.com/docs/build-skills)
- [Skill category inspiration](https://snyk.io/articles/top-claude-skills-3d-modeling-game-dev-shader-programming/)
- [Three.js game skills](https://github.com/majidmanzarpour/threejs-game-skills/tree/main/skills): evidence manifests, visual review, target-specific budgets.
- [Blender skills comparison](https://github.com/arjun988/blender-skills): catalog and packaging inspiration.

The community MCP implementation referenced by the last repository is not this suite's runtime. Reuse the separately configured official Blender Lab integration. No llama.cpp, competing add-on, paid service, automatic update, or copied third-party skill content is required.

Codex on Windows is the initial validation target. Other clients and operating systems are not yet certified. Decide distribution licensing before public release. This repository does not bundle Blender or its server.
